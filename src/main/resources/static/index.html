Definition of Done

  • ✓ Unit and controller tests pass
  • ✓ Checkstyle check completes
  • ✓ JaCoCo report is generated
  • ✓ Docker image builds successfully

Acceptance criteria · Add a student

Given / When / Then examples that define expected behavior

GIVEN

The student list does not contain roll number R100.

WHEN

A teacher submits Asha Patel with roll number R100.

THEN

A student is created and the API returns HTTP 201.

GIVEN

The student list already contains roll number R100.

WHEN

A teacher submits another student with roll number R100.

THEN

The API returns HTTP 400 and no duplicate is added.

What deployment means here: the workflow builds a Docker image and uploads the JAR and coverage report as artifacts. It does not publish to a live cloud server; that can be added after you choose a host.

CI

Continuous Integration

Automatically check code changes

  • ✓ Runs for pushes to main and pull requests
  • ✓ Compiles with the Maven wrapper
  • ✓ Runs unit and MockMvc tests
  • ✓ Checks Java style with Checkstyle
  • ✓ Generates and uploads JaCoCo coverage
CD

Delivery artifacts

Open a workflow run to inspect the result

  • JARDownload from the run’s Artifacts section
  • CoverageOpen the uploaded JaCoCo HTML report
  • DockerImage built in the job; not pushed to a registry

After pushing to GitHub: repository Actions tab → select “Student Management CI/CD” → open a run → inspect each step and logs.
